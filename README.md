(Рандомайзер)
Помощник для сомневающихся. Кликнул — получил ответ.

Что делает: Окно в виде магического шара. Ты вводишь свой вопрос (например: «Идти ли мне сегодня гулять?») и жмешь кнопку. Программа крутит красивую анимацию загрузки 2 секунды и выдает случайный ответ: «Да», «Нет», «Определенно да», «Даже не думай».

Чему научишься: Использовать модуль random, работать с задержкой времени и делать простую смену текста/картинок.
